# Experiment Scripts

Current scripts:

- `run_exp20_d2c13_2_aliasguard_clean.cmd`: current nine-run-per-corpus clean
  experiment with alias guard enabled;
- `run_exp20_d2c13_2_clean.cmd`: alternate D2C_13_2 clean launcher;
- `run_exp20_win95_run06_recover.cmd`: recovery path for the affected win95pts
  run;
- `run_sparql_parity.cmd`: independent producer/consumer Q1--Q7 parity command;
- `run_prov_alignment.cmd`: PROV-O alignment check over prepared artifacts.

Current scripts assume execution from the repository root and use paths relative
to it. Historical launchers are under `historical/`; they preserve earlier
experiment commands but may require adaptation to the current layout and local
data paths.
